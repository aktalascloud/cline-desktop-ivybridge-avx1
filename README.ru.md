# Cline Desktop AVX1 RU

Неофициальный форк [Cline](https://github.com/cline/cline) для Windows x64,
на базе Desktop 0.0.49 и актуального main. Цель — Ivy Bridge с AVX, F16C,
SSE4.2 и POPCNT без требования AVX2/FMA. [English](README.md).

В комплект входят Desktop, CLI, Hub и служба приложения. Поддержка локальных
и OpenAI-совместимых провайдеров, инструментов и MCP сохранена из Cline.
Добавляется русский интерфейс с переключением на английский. Пользовательский
текст, код, команды и идентификаторы API не переводятся.

Сборка ориентирована на **локальные LLM, особенно Strata** через
OpenAI-совместимый API. Доступны выбор локальной модели, уровни reasoning,
streaming, инструменты и MCP. Адрес провайдера и личные инструкции хранятся
в локальном профиле пользователя.

Голосовой ввод поддерживает потоковые модели и обычный Whisper-совместимый STT.
Выберите отдельную голосовую модель в настройках, запишите речь и нажмите «Стоп».
Для совместимости запись локально преобразуется в PCM WAV: моно, 16 кГц.
Текст вставляется в черновик без автоматической отправки агенту. Голосовой и
текстовый провайдеры настраиваются отдельно. Сервер должен поддерживать STT.

## Установка

Скачайте [текущий выпуск](https://github.com/aktalascloud/cline-desktop-ivybridge-avx1/releases/latest) или
[установщик Windows x64](https://github.com/aktalascloud/cline-desktop-ivybridge-avx1/releases/download/avx1-v1.0.7/Cline-Desktop-AVX1-RU-Setup.exe). Проверяемая система — Windows 10 LTSC 19044 x64, Xeon E5-2697 v2 и WebView2.

У форка собственные ID приложения, подписанные обновления, каталог данных и
один ярлык автозапуска. Другая установка Cline сохраняется отдельно.
Подпись Tauri не означает наличие публично доверенного сертификата Authenticode.

## Изменения и результаты

- [Обновление безопасности Next.js](https://github.com/cline/cline/pull/15146), адаптированное и дополненное обновлением до 16.4.3.
- [Обновление undici до 7.30.1](https://github.com/cline/cline/pull/15287).
- [Проверки дублирования истории](https://github.com/cline/cline/pull/15223): само исправление уже присутствует в upstream main.
- Новые чаты больше не восстанавливают удалённого провайдера: работает выбор reasoning настроенной локальной модели. Настройки старых диалогов сохраняются.
- 1.0.7: отдельные None/Low/Medium/High/XHigh, авторский Ultra и Adaptive бэкенда (`reason_mode=auto`) для явно совместимых локальных моделей. Без клиентского роутера и памяти. Окружение shell изолировано по сессиям, каталог MCP поддерживает защищённую пагинацию, обновлён совместимый адаптер Langfuse. [Реестр проверки](fork/review-20261027.json).
- 1.0.6: параметры генерации рядом с thinking и ответ до завершения на совместимом локальном сервере; дополнительный авторский Ultra только для XHigh. Проверены RU/EN и параметры запросов установленного CLI; улучшение качества модели не заявляется.
- 1.0.5: восстановление сессий, панель изменений и дополнительные локальные среды; коды PowerShell, hooks отмены, индикатор обновления, защита команд/junction, закрытие SQLite и расширенный русский перевод.
- Наши изменения: RU/EN, отдельные обновления форка, закрытие SQLite-соединений, безопасная работа с worktree в Windows и привязка MCP OAuth к issuer с SDK 1.32.2.

[Синтетический тест истории](fork/history-benchmark.json) устраняет рост handles
(с +300 до 0 за 100 опросов), но медиана времени растёт с 1240,3 до 1378,7 мс.
Это исправление утечки ресурсов; общего ускорения и роста LLM tokens/s не заявляется.
Fat LTO уменьшает нативный EXE; общего ускорения не подтверждено. [Замеры и ограничения](fork/performance.md). Интерактивная GUI-проверка снята владельцем с обязательных условий. Bun 1.4.2 x64 и baseline
содержат одинаковый исполняемый файл; оба запустились на этом CPU.
Bun/JSC, WebView2 и нативные npm-библиотеки — готовые компоненты, которые не
перекомпилируются флагами Rust. PGO, affinity/NUMA pinning, CUDA и модели не добавлены.

[Сборка и выпуск](fork/README.md), [реестр патчей](fork/review-ledger.json),
[состояние проверок](fork/qualification.json). Проверены установленное обновление,
подпись и отклонение изменённого файла, протокольные сценарии и нативные профили.
[Очистка публичной истории](fork/history-policy.md).

а также ссылки на соответствующие исходники входят в установщик.

TUI встроенного CLI и внешние сообщения об ошибках могут оставаться английскими.
Полная интерактивная проверка GUI и отрисовки длинной истории не заявляется. Настройки провайдера и промпт хранятся приватно.

Для управления Ollama/LM Studio нужен отдельно установленный совместимый сервер. Серверы и модели не включены, не устанавливались и не проверялись на этом железе. CI проверяет затронутые компоненты и использует закреплённые кэши; прежние замеры остаются историческими.
