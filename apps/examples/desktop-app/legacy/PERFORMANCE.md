# Производительность Cline Desktop Legacy 0.0.51-legacy.2

Целевой процессор — Core 2 Duo P9700 (Penryn), два ядра, x64 и SSE4.1. Установщик проверяет Windows 7 SP1 или новее и SSE3 до распаковки. В сборку входит готовый Electron Legacy 44.11.5. Флаги `-march=penryn`, `-mtune=penryn`, LTO и PGO требуют компиляции движка из исходников и здесь не применялись. Для такой сборки нужно отдельно проверить инструкции и рантайм Chromium, Node и SQLite на Windows 7 и 8.1. Для P9700 следует исключить SSE4.2, POPCNT и AVX из обязательного набора инструкций. [Исходники Electron Legacy](https://github.com/Alex313031/electron-legacy/tree/v44.11.5-src) · [Проверка SSE3 в Win32](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-isprocessorfeaturepresent)

## Запуск и интерфейс

- Создание окна и загрузка локального интерфейса начинаются одновременно с запуском sidecar. Первый запрос ждёт его адрес по IPC. Нативный обработчик проверяет окно и фрейм, затем интерфейс подключается к loopback WebSocket.
- Настройки загружаются отдельным пакетом. Наведение на кнопку или перевод на неё фокуса начинает загрузку до клика. Панель терминала, список сессий и файловые панели по-прежнему загружаются по необходимости.
- Чат использует сгруппированные и мемоизированные строки. Обработчик потока накапливает дельты и ограничивает обновления примерно до 20 коммитов React в секунду. Для оценки длительной сессии нужны отдельные замеры прокрутки, разметки Markdown и длинных кадров при локальном повторе потока. Виртуализация строк меняет геометрию и якоря прокрутки. Её нужно проверять на длинном тексте, свёрнутых инструментах и изображениях.
- В установщик входят минифицированные пакеты SDK, статический интерфейс Next.js и ресурсы Chromium en-US/ru. Сохранены лимит дискового кэша в 32 МиБ, два потока libuv и локальный WebSocket без сжатия. В обычном запуске движок выбирает аппаратное ускорение и режим фоновой отрисовки.

## Методика

Параллельный и последовательный запуск сравниваются на одном бинарнике с новым профилем на каждый запуск. Поля `pageLoaded`, `sidecarReady` и `hubChecked` отсчитываются в миллисекундах от начала основного JavaScript. `pageLoaded` соответствует завершению загрузки документа, а `hubChecked` — ответам о готовности Hub, настройках и провайдерах. Загрузка EXE до выполнения JavaScript в эти числа не входит.

Переключение — первый вход в настройки после обхода onboarding в тестовом профиле. Вариант `--settings-intent` даёт пакету 300 мс после фокуса и перед кликом. Временем переключения считается появление DOM настроек. Поля кадров показывают интервалы `requestAnimationFrame` за 1,5 с в offscreen-режиме. Они описывают тестовый рендер. Частота физического дисплея, драйвер и плавность длительного чата требуют отдельного замера.

```powershell
$profile = New-Item -ItemType Directory (Join-Path $env:TEMP ("cline-bench-" + [guid]::NewGuid()))
$out = Join-Path $profile.FullName 'report.json'
$p = Start-Process -WindowStyle Hidden -PassThru .\ClineLegacy.exe -ArgumentList @(
  "--smoke-test=`"$out`"", '--profile-switch', '--settings-intent'
)
if (!$p.WaitForExit(95000)) { throw 'Smoke test timed out' }
Get-Content -LiteralPath $out -Raw
```

Для контрольного запуска добавьте `--serial-startup`. Для замера переключения без предподгрузки опустите `--settings-intent`. Для измерения только запуска опустите `--profile-switch`. Новый путь к отчёту в новом каталоге даёт чистый профиль.

## Результаты 28 ноября 2026 года

Windows 11 Pro 26200, Xeon E5-2696 v3. Процесс запуска теста ограничен маской affinity `0x3`. На каждое сочетание режима запуска и предварительной загрузки выполнено по три прогона, всего 12 новых профилей. Часть прогонов шла при фоновой упаковке NSIS. Это замеры относительных задержек на тестовой машине. Частоты, кэш и GPU Penryn не моделировались.

| Метрика, медиана | Контроль | Новый режим |
| --- | ---: | ---: |
| Завершение загрузки страницы, последовательный и параллельный запуск | 3 689 мс | 2 520 мс |
| Hub и ответы контрольных запросов, последовательный и параллельный запуск | 5 546 мс | 5 926 мс |
| Клик до DOM настроек, без и с предварительной загрузкой | 636 мс | 438 мс |
| Максимальный интервал callback кадров в прогоне, без и с предварительной загрузкой | 852 мс | 705 мс |

Интерфейс загружался раньше, а проверка готовности Hub заняла примерно на 380 мс больше. Предварительная загрузка сокращала задержку после клика при тестовом интервале фокуса 300 мс. В offscreen-режиме медиана количества callback кадров за прогон составила 4 и 28,5 соответственно. Разброс велик, поэтому эти значения не дают оценки FPS или подтверждения снижения джанка на физическом P9700.

## Проверка исходников и PR

Официальный Desktop оставался на `desktop-v0.0.51`. Коммит `main` после тега выпустил VS Code и не менял Desktop или SDK. Код повторного восстановления после переполнения из [PR 15676](https://github.com/cline/cline/pull/15676) уже присутствовал в ветке. Поля контекста при обнаружении моделей из [PR 15677](https://github.com/cline/cline/pull/15677) были адаптированы в существующем патче. [PR 15678](https://github.com/cline/cline/pull/15678) относится к Pino в бинарнике Bun. В Legacy запускается отдельный Node-процесс Electron.

[PR 15886](https://github.com/cline/cline/pull/15886) исправляет разрешение путей входных файлов при упаковке бинарника CLI. Legacy собирает sidecar прямо из исходников на диске проекта и список лицензий формируется в его конвейере. [PR 14208](https://github.com/cline/cline/pull/14208) читает локальную историю использования разных клиентов. Квоту подписки в этой сборке запрашивает ChatGPT. [PR 11148](https://github.com/cline/cline/pull/11148) касается обновления OAuth, которым здесь управляет существующая блокировка SDK.

Вход ChatGPT берётся из официального провайдера Cline. Панель лимитов запрашивает квоту по пути, который использует Codex. Данные OAuth остаются в sidecar. [Планы ChatGPT с Codex](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan) · [Исходник клиента лимитов Codex](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client/rate_limit_resets.rs)

Модели FreeLLM сверены 28 ноября 2026 года. У всех трёх прошёл синтетический потоковый вызов инструмента через Kilo без ключа. Ранжирование учитывает действующие бесплатные модели с опубликованным сопоставимым баллом и инструментами.
