# Cline Desktop Legacy RU 0.0.51-legacy.3

Неофициальная сборка Cline Desktop для 64-битных Windows 7 SP1, 8 и 8.1. Целевой процессор — Intel Core 2 Duo P9700 (Penryn, 2 ядра, SSE4.1). Интерфейс и SDK взяты из тега `desktop-v0.0.51`.

NSIS устанавливает приложение для текущего пользователя и добавляет ярлык в «Пуск». На странице компонентов можно отметить «Создать ярлык на рабочем столе». При тихой установке для этого предусмотрен параметр `/DESKTOPSHORTCUT`. WebView2 и Bun на компьютере пользователя не нужны. Настройки, история и ключи этого порта хранятся в `%APPDATA%\Cline Desktop Legacy`, отдельно от стандартного клиента. Удаление через «Программы и компоненты» сохраняет их. Установщик не подписан.

Вместо Tauri и Bun используется [Electron Legacy 44.11.6](https://github.com/Alex313031/electron-legacy/releases/tag/v44.11.6) с Node.js 24.22.3. Интерфейс открывается из локальной сборки, управление идёт через WebSocket на loopback с проверкой origin и токена. Лимит дискового кэша Chromium — 32 МиБ. Пул ввода-вывода Node ограничен двумя потоками, WebSocket передаёт локальные сообщения без сжатия. В инсталляторе оставлены ресурсы Chromium для en-US и ru.

Доступны отдельный профиль, выбор папки и штатный локальный Hub. Встроенный терминал, нативный трей, автоматическое обновление и внешние SSH-помощники требуют дополнительной адаптации. Для генерации настройте модель в Cline.

Русский интерфейс включён по умолчанию. В настройках можно переключиться на English. Автокомпакт включён по умолчанию, порог составляет 90 000 токенов, лимит ввода — 120 000, сохраняется до 40 последних сообщений с учётом бюджета модели. Полная история остаётся на диске.

В списке провайдеров доступен FreeLLM через Kilo Gateway. Для него ключ не нужен. Каталог включает ERNIE 5.5 Flash Preview, Beam 1.0 и Nemotron 3.5 Super VL с баллами 31, 18 и 14 по Artificial Analysis Intelligence Index среди бесплатных моделей шлюза с подтверждённой оценкой и поддержкой инструментов. Потоковые вызовы инструментов у всех трёх проверены 28 ноября 2026 года. У шлюза общий лимит 200 запросов в час на IP. Запросы уходят в облако и могут журналироваться. Бесплатный endpoint NVIDIA предназначен для пробного использования, без личных или конфиденциальных данных. [Методика и оценки](https://artificialanalysis.ai/models/releases) · [Условия доступа Kilo](https://kilo.ai/docs/gateway/models-and-providers)

Перенесены патчи [02–04 из ветки AVX1](https://github.com/aktalascloud/cline-desktop-legacy/tree/292f1627d48d97f078dfd9f9de551dc9c1c387a0/patches/local). Legacy использует свой установщик и собственный рантайм для Penryn.

## Подписка ChatGPT и команды агента

В настройках провайдеров выберите **ChatGPT Subscription (Codex)** и войдите через браузер. В карточке после входа появится оставшийся процент квоты по окнам и время сброса, если ChatGPT возвращает эти данные. Кнопка обновления запрашивает актуальные лимиты. Для такого входа достаточно подписки с доступом к Codex. Лимиты берутся из ответа ChatGPT, независимо от счётчика токенов Cline.

Агент использует штатный Windows PowerShell без загрузки профиля. Команды передаются через UTF-8 stdin. Для CMD задайте `CLINE_LEGACY_SHELL=cmd` в окружении до запуска приложения и его Hub. При смене окружения завершите приложение и его Hub, чтобы новый сеанс получил настройку. Команду для CMD окружает внешняя пара кавычек, а внутренние кавычки передаются без экранирования Node. Для русскоязычного вывода на старых системах используйте PowerShell с UTF-8. Вывод внешних утилит в CMD зависит от их кодовой страницы.

[Исследование производительности](PERFORMANCE.md) и сценарий замеров входят в исходники.

## Сборка

На современной Windows установите Bun 1.4.2 и Node.js 24. Скачайте [архив Electron Legacy x64](https://github.com/Alex313031/electron-legacy/releases/download/v44.11.6/electron-v44.11.6-win32-x64.zip), проверьте SHA-256 и распакуйте его. SHA-256 архива — `c324827bdb9b9b23aa9cffa4891eea7422c0f43e3949800ae624696e3cb68a34`. Для упаковки используется [NSIS 3.13](https://github.com/tauri-apps/binary-releases/releases/download/nsis-3.13/nsis-3.13.zip).

Из корня репозитория выполните:

```powershell
bun install --frozen-lockfile
bun run build:sdk
$env:NEXT_TELEMETRY_DISABLED = '1'
bun -F @cline/code build:web
bun apps/examples/desktop-app/legacy/package.mts C:\Build\ElectronLegacy C:\Build\NSIS\makensis.exe ..\dist
```

Результат — `Cline_0.0.51-legacy.3_x64-setup.exe`. После упаковки для повторной сборки заново выполните `build:web`, чтобы восстановить карты исходников для списка лицензий.

Для нативного Electron с профилем Penryn соберите x86-проверку SSE4.1 из `penryn-cpu-check.c`. Из x86 Native Tools Prompt выполните в этой папке:

```cmd
cl /nologo /c /O1 /GS- /Zl /W4 /WX penryn-cpu-check.c
link /nologo /nodefaultlib /subsystem:windows,6.01 /entry:CheckCpu@0 /machine:x86 /out:penryn-cpu-check.exe penryn-cpu-check.obj kernel32.lib
```

В вызове `package.mts` укажите путь к этому EXE четвёртым аргументом. Установщик выполнит проверку до распаковки приложения. Используйте этот аргумент для Electron, собранного с `cline_enable_penryn=true`. [Патчи и профиль Electron](../../../../patches/README.md)

После установки для проверки запуска выполните `ClineLegacy.exe --smoke-test=C:\Temp\cline-qa\result.json`. Каталог результата служит изолированным профилем проверки. Отчёт содержит язык интерфейса, версию, настройки автокомпакта, список моделей FreeLLM, состояние подключения к Hub и отметки времени запуска. `--profile-switch` дополнительно измеряет первый переход к настройкам.
